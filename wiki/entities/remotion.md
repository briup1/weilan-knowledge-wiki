# Remotion

Remotion 是一个基于 React 的编程式视频创作库，允许开发者用熟悉的组件化思维和 TypeScript 代码来创建视频，而非依赖 After Effects 或 Premiere Pro 等传统剪辑软件。

## 核心组件与特性

- **React 组件化视频**：将视频拆分为可复用的 React 组件，每个组件管理自己的动画、样式和生命周期，天然支持模块化开发。
- **TypeScript 全栈**：从视频逻辑到动画参数全程类型安全，IDE 自动补全和重构能力直接复用到视频项目中。
- **可编程动画**：利用 React 的声明式语法和 CSS/Canvas/WebGL 动画库，精确控制每一帧的视觉效果，动画逻辑与表现完全透明。
- **免费开源**：Remotion 核心库本身免费，仅需为渲染服务器或 Remotion Studio 等增值服务付费。
- **代码驱动工作流**：视频即代码，天然支持版本控制（Git）、代码审查、自动化测试和 CI/CD 集成。

## 使用指南与最佳实践

- **零基础入门**：配合 OpenCode 等 AI 助手，用户只需用自然语言描述视频效果（如"背景黄色，大笑表情从左边弹出，下面写「太牛了」，带弹跳效果"），AI 即可自动生成 Remotion 代码并渲染为 MP4。
- **常见时长参考**：微信贴图 3-5 秒、产品介绍视频 15-30 秒、科普视频 30-60 秒、品牌片头 5-10 秒。
- **风格化渲染**：可通过 CSS 和外部库实现宫崎骏风格、赛博朋克风格、迪士尼风格、极简风格等多样化视觉效果。
- **适用场景**：社交媒体表情包、产品功能展示、数据可视化动画、课程介绍、个人品牌片头、节日祝福视频等。
- **与传统方式对比**：学习门槛更低（会说话即可借助 AI 生成）、修改更方便（改代码即可重新渲染）、无需购买昂贵的专业软件授权。

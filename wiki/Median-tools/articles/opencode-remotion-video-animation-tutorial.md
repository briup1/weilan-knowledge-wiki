> 不需要任何编程基础，只需要会说话就能做出视频。本文介绍如何用 OpenCode + Remotion，从零开始制作微信贴图、产品介绍视频、科普动画等内容。

## 什么是 Remotion？

**官方定义**：用代码做视频的工具。

**人话版**：

- **PPT** = 拖拽元素做幻灯片
- **Remotion** = 用代码"写"幻灯片，输出为视频

### 与传统方式对比

| 对比项 | 传统方式（AE/Pr） | Remotion 方式 |
| --- | --- | --- |
| 学习难度 | 高 | 低（会说话就行） |
| 修改方便度 | 麻烦 | 改句话就行 |
| 成本 | 付费软件/请人 | 免费 |
| 效果 | 专业 | 足够日常使用 |

## 准备工作

在 OpenCode 中安装 Remotion 技能：

```
帮我安装 remotion-best-practices 技能
```

OpenCode 会自动完成安装，过程中有问题会主动告知。

## 实战案例

### 实战 1：微信动态贴图表情包

**场景**：聊天时发与众不同的表情包，或做专属祝福动画。

**提示词示例**：

```
帮我做一个微信表情包，时长 3 秒，背景是黄色，
上面有一个大笑的表情图标从左边弹出来，
下面写着「太牛了」三个字，带一点弹跳效果
```

**OpenCode 会做什么**：
1. 写好动画代码
2. 渲染生成 MP4 视频
3. 告知文件位置

**可做的类型**：节日祝福、点赞类（666）、搞笑类、鼓励类。

### 实战 2：产品介绍视频

**场景**：向朋友介绍产品，或做科普视频让别人一眼看懂。

**提示词示例**：

```
帮我做一个 20 秒的 OpenCode 介绍视频。
开头是一个笔记本电脑从屏幕中间弹出，带一点弹性效果。
然后文字从下方淡入，写着「OpenCode：你的 AI 助手」。
然后下一行显示「会说话就能用」。
```

**可做的类型**：产品功能展示、公司简介动画、课程介绍视频、品牌故事短片。

## 风格与配乐

**风格关键词**：
- "宫崎骏风格" — 清新、自然
- "赛博朋克风格" — 科技感、霓虹
- "迪士尼风格" — 可爱、卡通
- "极简风格" — 干净、现代

**配乐**：直接说"帮我加上背景音乐"或"配一段轻快的音乐"即可。

## 常见问题

**Q：需要会写代码吗？**
A：不需要。告诉 OpenCode 你想要什么，它帮你写代码。

**Q：生成的视频在哪里？**
A：OpenCode 会告诉你文件位置，可以直接分享到微信。

**Q：收费吗？**
A：Remotion 本身免费，但渲染可能消耗一些算力。

**Q：不会描述想要的视频怎么办？**
A：直接告诉 OpenCode 你的用途和场景，比如"我想做一个生日祝福视频"，它会帮你设计。

这就是 AI 时代的"视频自由"。

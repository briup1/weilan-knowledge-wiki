# OpenScreen：开源桌面录屏与视频编辑工具

## 摘要

OpenScreen 是一个开源的桌面录屏与视频编辑工具，专注于"产品演示"和"操作讲解"场景，定位为 Screen Studio 的免费开源替代方案。项目在 GitHub 上已获得上万 Star，采用 MIT 协议完全免费、无水印、无功能限制、可商用。它将"录屏 + 后期处理"整合在一个工具中，让普通人也能轻松做出接近专业级的视频。核心亮点包括动态缩放（镜头自动跟随鼠标）、平滑动画过渡（Motion Blur、自定义动画曲线）、注释与强调元素、丰富的视觉风格定制和多格式导出（MP4/GIF，多比例适配）。技术栈为 Electron + React + TypeScript + PixiJS，支持 Windows、macOS 和 Linux。

## 核心要点

- **完全免费开源**：MIT License，无月费、无水印、无功能限制、可商用，与 Screen Studio（收费）形成直接对比
- **专注产品演示场景**：不做"大而全"的视频编辑器，聚焦软件演示、教程讲解、操作说明三大场景，体验更流畅
- **动态缩放（杀手级功能）**：在时间轴上设置缩放点，指定缩放位置和控制速度，实现镜头自动跟随鼠标、放大关键操作区域
- **平滑动画与动效**：内置 Motion Blur（运动模糊）、平滑缩放过渡、自定义动画曲线，让视频更"丝滑"
- **视频编辑能力**：支持裁剪画面区域、删除多余片段、调整播放速度（快进无意义操作），以及添加文字/箭头/图片注释
- **视觉风格定制**：可调整背景（渐变/图片/纯色）、圆角、阴影、模糊效果，无需设计基础也能做出"好看"的视频
- **多格式导出**：MP4、GIF，支持 16:9 / 9:16 / 1:1 多种比例，一份素材可适配横屏和短视频多平台
- **技术栈**：Electron（跨平台桌面框架）、React（UI）、TypeScript（类型安全）、PixiJS（高性能渲染），开发门槛低、社区易参与
- **目标用户**：开发者（功能演示、技术教程）、自媒体/内容创作者（软件推荐、教程视频）、产品经理/运营（产品介绍、walkthrough）、教育从业者（课程录制、操作讲解）

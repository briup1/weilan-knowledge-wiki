# Google Cloud：Agent Platform 评估与治理更新

## 摘要

Google Cloud 2026-07-30 的更新把两件事拆开：可观测性回答 Agent 做了什么，评估回答做得好不好。开发期要优化的指标和上线后的评分由同一引擎执行。

## 核心要点

- Observability 和 Evaluation 不是同一个问题，但应消费同一套运行证据。
- 更新还把仿真、身份和安全放进同一轮治理能力，说明评估结果要能接到权限和发布控制。

## 局限

这是产品更新说明。自适应 Rubric 怎么训练、怎么校准、偏差怎么控，以及线上检测的统计方法和成本，文中都没有公开。
